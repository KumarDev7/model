# AI Agent Guidelines

This repository enforces strict conventions for all AI agents, assistants, and automated tools contributing to the codebase.

---

## 1. Git Commit Guidelines

### No Co-Author Metadata
- **Never include co-author trailers**: Do **NOT** add `Co-Authored-By:`, `Co-authored-by:`, or any variation in commit messages.
- **No AI / session metadata**: Do **NOT** append AI tool session identifiers, prompts, or AI platform URLs (such as `Claude-Session:`, agent footers, or bot watermarks) to commit messages.

### Clean Commit Messages
- **Format**: Write clean, professional commit messages focused strictly on the changes made.
- **Structure**:
  - A clear, concise subject line (imperative mood, e.g., `Add feature X`, `Fix issue Y`).
  - Optional body separated by an empty line describing *what* and *why*, without unnecessary noise.
- **No spam**: Avoid unnecessary noise, autogenerated boilerplate, or verbose attribution tags.

### Commit Author & Identity
- **Use default git user**: Always use the default configured git identity (`user.name` and `user.email`) already configured in the local or global Git environment.
- **Do not alter or spoof author details**: Never override the author or committer with AI names (e.g., Claude, Agent, Bot) or any alternate user identity unless explicitly directed by the user.
